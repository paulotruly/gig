# 026: aplicativo instalável (PWA)

**Situação:** `concluída`
**Depende de:** 024 (favicon e layout do `apps/web`)
**Referências:** relatório do PWABuilder para https://gigreat.online; `specs/arquitetura.md`

## Objetivo

Permitir instalar o GiG no celular e no computador como aplicativo (tela inicial, janela própria) e preparar o pacote para lojas pelo PWABuilder. Antes desta tarefa, o PWABuilder não encontrava manifesto nem service worker.

## Requisitos

- R1: o site publica um manifesto válido com nome, cores, `start_url`, `display: standalone` e ícones 192, 512 e maskable.
- R2: o site registra um service worker em produção.
- R3: o service worker nunca guarda respostas de `/api` ou `/webhooks`; dados financeiros não ficam no cache do aparelho.
- R4: sem conexão, a navegação mostra uma página offline em pt-br.

## Fora do escopo

- Uso offline das telas com dados, sincronização em segundo plano e notificações push.
- Publicação nas lojas (Play Store, Microsoft Store, App Store): exige contas de desenvolvedor da equipe.

## Critérios de aceite

- [x] C1: `/manifest.webmanifest` responde com os campos de R1.
- [x] C2: `/sw.js` responde com `Cache-Control: no-cache`.
- [x] C3: depois da implantação, o PWABuilder não aponta erro de manifesto nem de service worker para https://gigreat.online.

## Plano técnico

- `apps/web/src/app/manifest.ts`: manifesto pelo recurso de metadados do Next.
- `apps/web/public/icons/`: ícones gerados com o `sharp` a partir do `apple-icon.png` (180 px).
- `apps/web/public/sw.js` e `apps/web/public/offline.html`: rede primeiro para páginas, cache primeiro para `/_next/static` e `/icons`.
- `apps/web/src/components/pwa/ServiceWorkerRegister.tsx`: registro só em produção.
- `apps/web/next.config.js`: cabeçalho sem cache para `/sw.js`.
- `apps/web/public/.well-known/assetlinks.json`: liga o app Android `online.gigreat.app` ao domínio, para o app abrir sem a barra do navegador.
